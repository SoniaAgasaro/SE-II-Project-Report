# ADR 006: Barcode Scanner Handling via Keyboard Emulation

## Status
Accepted

## Context
Warehouse features (Picking, Receiving, Put-Away, Item Search) require rapid data entry. Workers will use handheld barcode scanners. Integrating directly with proprietary scanner SDKs for various hardware brands is complex.

## Decision
We will configure the frontend to handle barcode scanners as standard "Keyboard Emulation" devices. The UI will have auto-focusing input fields that listen for rapid keystrokes ending with an "Enter" key (which scanners send automatically). 

## Consequences
- **Positive:** Zero integration effort with specific hardware brands. Any standard USB or Bluetooth scanner will work immediately with the web application.
- **Negative:** The UI must be carefully designed to ensure focus is always on the correct input field, preventing scanned data from being lost or typed into the wrong box.
