# ADR 007: Non-Blocking Discrepancy Handling

## Status
Accepted

## Context
During receiving (Feature 11) and delivery (Feature 16), quantities received/delivered may not match the ordered/shipped quantities. If the system blocks the workflow when a discrepancy occurs, it will halt warehouse operations.

## Decision
The system will allow workers to record actual quantities without blocking the workflow. The system will automatically calculate the difference (shortage or overage) and flag the record with a `discrepancy_status`. 

## Consequences
- **Positive:** Warehouse operations continue smoothly. The discrepancies are captured silently and made available for the manager to review later via the reporting dashboard (Feature 18).
- **Negative:** Requires the frontend to clearly display discrepancies to the user without being alarming, and requires managers to actively monitor the exception reports.
